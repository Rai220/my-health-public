# ⚠️ ВСЕ ДАННЫЕ В ЭТОЙ ПАПКЕ ВЫМЫШЛЕНЫ

Это **демонстрационное досье**. Пациента «ИП» не существует; все имена, даты, цифры, диагнозы, названия лабораторий и результаты придуманы для показа структуры.

**Не использовать как медицинский пример.** Значения подобраны так, чтобы показать формат, а не чтобы быть клинически образцовыми.

## Что здесь показано

| Файл | Что демонстрирует |
|---|---|
| [BIO.md](BIO.md) | Минимальная карточка |
| [SUMMARY.md](SUMMARY.md) | Сводка на одну страницу со ссылками вместо копий данных |
| [PROBLEMS.md](PROBLEMS.md) | Диагнозы со статусами `active / resolved / suspected / ruled_out` |
| [BODY.md](BODY.md) | Ряд веса с **обязательной колонкой методики**, включая строку с «неизвестно», и **отозванный вывод** в `<details>` |
| [VITALS.md](VITALS.md) | Разрозненные замеры АД → полный **протокол СКАД** с усреднением |
| [TESTS.md](TESTS.md) | Анализы с указанием лаборатории; межлабораторный ряд помечен как ненадёжный |
| [MEDS.md](MEDS.md) | Препарат с эффектом, побочками и мониторингом |
| [DIARY.md](DIARY.md) | Результаты опросников — **без** копирования текста форм |
| [HYPOTHESES.md](HYPOTHESES.md) | Гипотеза с критерием проверки, сформулированным **заранее** |
| [TODO.md](TODO.md) | Задачи с обоснованием, ссылающимся на владельца данных |

## Главное, что стоит вынести из примера

1. **Колонка «Методика / источник» заполнена в каждой строке.** Где методика неизвестна — так и написано, и такая точка не участвует в сравнениях.
2. **Один факт живёт в одном файле.** Сводка и задачи дают ссылки, а не копии цифр.
3. **Ошибочные выводы не удаляются**, а сворачиваются в `<details>` с причиной отзыва.
4. **Ряд из разных лабораторий** помечен явно — на нём не строятся выводы.
