# Health — медицинская база

Личная медицинская база в Markdown для ведения пациентов с помощью AI-ассистента.

## Демонстрация

🧬 **[Дашборд генетического профиля](https://rai220.github.io/my-health-public/dashboard/)** — игровая визуализация фармакогенетического билда. **Все данные вымышлены** — это пример формата, а не чей-то реальный геном. Не медицинская рекомендация.

📋 **[Пример досье пациента](example_patient/README.md)** — заполненное досье с вымышленными данными: ряд веса с колонкой методики, полный протокол СКАД с усреднением, отозванный вывод, межлабораторный ряд с пометкой о непригодности.

## Для чего

- Единый источник правды по диагнозам, лечению, обследованиям
- Отслеживание динамики во времени
- Подготовка к визитам к врачу
- AI-анализ медицинских данных и генетики

## Структура

```
health/
├── example_patient/       # Пример досье — ВСЕ ДАННЫЕ ВЫМЫШЛЕНЫ
├── {пациент}/             # Ваши пациенты
│   ├── BIO.md             # Кто это: возраст, рост, аллергии
│   ├── SUMMARY.md         # Сводка на одну страницу
│   ├── PROBLEMS.md        # Диагнозы со статусами
│   ├── BODY.md            # Вес, обхваты, состав тела
│   ├── VITALS.md          # АД, пульс, глюкоза
│   ├── DIARY.md           # Дневник симптомов + результаты опросников
│   ├── TESTS.md           # Анализы и обследования
│   ├── MEDS.md            # Препараты
│   ├── HYPOTHESES.md      # Гипотезы с критериями проверки
│   ├── TODO.md            # Задачи
│   └── genetic/           # Расшифровки геномов — НЕ КОММИТИТСЯ
├── drugs/                 # Справочник препаратов
├── questionnaires/        # Тексты шкал (GAD-7, PHQ-9, MDQ)
├── tools/                 # Инструменты анализа
├── TEMPLATE/              # Шаблон для нового пациента
├── AGENTS.md              # Инструкции для AI-ассистента
└── README.md
```

Описание файлов пациента — в [AGENTS.md](AGENTS.md). Готовый пример — [example_patient/](example_patient/README.md).

## Быстрый старт

### 1. Создать пациента

```bash
cp -r TEMPLATE/ имя_пациента/
```

### 2. Заполнить файлы

Минимум для старта: `BIO.md`, `SUMMARY.md`, `PROBLEMS.md`.

### 3. Использовать с AI

Откройте проект в Cursor / Claude Code. AI-ассистент автоматически подхватит инструкции из `AGENTS.md`.

## 🔴 Приватность

Это личные медицинские данные. Перед первым коммитом:

1. **Сделайте репозиторий приватным**, если в нём будут реальные данные.
2. **Проверьте, что `genetic/` игнорируется**: `git status --porcelain пациент/genetic/` должно быть пусто. Подробно, что куда кладётся и почему геном опаснее остальных данных, — в [TEMPLATE/genetic/README.md](TEMPLATE/genetic/README.md).
3. **Помните, что геном — не только ваш**: ребёнок разделяет с вами ~50% вариантов, родитель и сибс тоже. Публикуя свой профиль, вы публикуете часть данных родственников.

В этом репозитории **реальных пациентов нет** — только структура, справочники и вымышленный пример.

## Соглашения

| Что | Формат |
|-----|--------|
| Даты | `YYYY-MM-DD`. Приблизительные — `YYYY` или `YYYY-MM` с пометкой `≈` |
| Источники | Указывать кто/откуда: врач, лаборатория, самонаблюдение |
| Статусы диагнозов | `active` / `resolved` / `suspected` / `ruled_out` |
| Повторяющиеся данные | Таблицы (лекарства, визиты, анализы) |
| **Методика замера** | 🔴 Обязательная колонка в каждой таблице замеров. Пустая ячейка недопустима, `неизвестно` — валидное значение |
| Отозванные выводы | Не удаляются, а сворачиваются в `<details>` с причиной отзыва |
