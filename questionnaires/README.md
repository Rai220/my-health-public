# Стандартизированные опросники

Тексты валидированных шкал — **один файл на инструмент**, по образцу [`drugs/`](../drugs/README.md).

**Зачем отдельный каталог.** Тексты опросников одинаковы для всех пациентов. Три пустых формы (GAD-7, PHQ-9, MDQ) — это ~107 строк, которые при копировании шаблона попадут к каждому новому пациенту и разъедутся при правках. Теперь текст лежит здесь в одном экземпляре, а **в файле пациента хранятся только результаты**: дата, сумма, интерпретация.

## Как пользоваться

1. Открыть нужный файл здесь, заполнить с пациентом.
2. Записать **только итог** в `<пациент>/DIARY.md` — дата, сумма по шкале, интерпретация, кто проводил.
3. Не копировать текст вопросов в файлы пациента.

## Доступные инструменты

| Файл | Что измеряет | Диапазон | Частота |
|---|---|---|---|
| [GAD-7.md](GAD-7.md) | Генерализованная тревога | 0–21 | раз в 2–4 недели |
| [PHQ-9.md](PHQ-9.md) | Депрессия | 0–27 | раз в 2–4 недели |
| [MDQ.md](MDQ.md) | Скрининг биполярного спектра | да/нет + критерии | однократно для базовой линии |

## Оговорки, общие для всех шкал

- **Это скрининг, а не диагноз.** Балл выше порога означает «нужна клиническая оценка», а не название болезни.
- **Самоотчёт.** У пациентов с алекситимией самооценка эмоций систематически занижена — низкий балл не равен отсутствию симптома. Проверить в `PROBLEMS.md`, отмечена ли такая особенность.
- **Сравнивать можно только с собой** и только при одинаковых условиях заполнения. Смена обстановки, времени суток или того, кто задаёт вопросы, ломает сопоставимость — та же проблема, что с методикой замера обхватов.
- **Фиксировать контекст**: кто проводил (сам / врач), когда, на фоне какой терапии. Без этого ряд не читается.
