# GAD-7 — Генерализованное тревожное расстройство

**Что измеряет**: уровень генерализованной тревоги за последние 2 недели.
**Частота**: раз в 2–4 недели для мониторинга терапии.
**Результаты записывать в**: `{patient}/DIARY.md` — только дата, сумма, интерпретация, кто проводил.

## Вопросы

За последние 2 недели, как часто вас беспокоили следующие проблемы?

| # | Вопрос | 0 | 1 | 2 | 3 |
|---|--------|---|---|---|---|
| 1 | Нервозность, тревога, ощущение "на взводе" | | | | |
| 2 | Невозможность прекратить или контролировать беспокойство | | | | |
| 3 | Чрезмерное беспокойство о разных вещах | | | | |
| 4 | Трудности с расслаблением | | | | |
| 5 | Такое беспокойство, что трудно усидеть на месте | | | | |
| 6 | Легко раздражаюсь или становлюсь нетерпеливым | | | | |
| 7 | Чувство страха, как будто должно случиться что-то ужасное | | | | |

**Шкала ответов:**

- **0** = Совсем нет
- **1** = Несколько дней
- **2** = Более половины дней
- **3** = Почти каждый день

## Интерпретация суммы

| Сумма | Уровень |
|---|---|
| 0–4 | Минимальная тревога |
| 5–9 | Лёгкая тревога |
| 10–14 | Умеренная тревога |
| 15–21 | Тяжёлая тревога |

**Порог направления к специалисту**: ≥10 обычно считается показанием к клинической оценке.

## Оговорки

- Шкала не различает тревогу и её причину. Повышенный балл при постбариатрической гипогликемии, гипертиреозе или отмене препарата — это не «тревожное расстройство», а адренергические симптомы. Соматические причины исключаются отдельно.
- Пункты 1, 5 и 6 пересекаются с симптомами СДВГ и с побочными эффектами стимуляторов.
- См. общие оговорки в [README.md](README.md).
