# PHQ-9 — Депрессия

**Что измеряет**: выраженность депрессивной симптоматики за последние 2 недели.
**Частота**: раз в 2–4 недели.
**Результаты записывать в**: `{patient}/DIARY.md` — только дата, сумма, интерпретация, кто проводил.

## Вопросы

За последние 2 недели, как часто вас беспокоили следующие проблемы?

| # | Вопрос | 0 | 1 | 2 | 3 |
|---|--------|---|---|---|---|
| 1 | Мало интереса или удовольствия от дел | | | | |
| 2 | Подавленность, депрессия, безнадёжность | | | | |
| 3 | Проблемы с засыпанием/сном или слишком много сна | | | | |
| 4 | Чувство усталости или мало энергии | | | | |
| 5 | Плохой аппетит или переедание | | | | |
| 6 | Плохое мнение о себе, чувство неудачника | | | | |
| 7 | Трудности сосредоточиться (читать, смотреть ТВ) | | | | |
| 8 | Замедленность или наоборот беспокойство/суетливость | | | | |
| 9 | **Мысли о том, что лучше бы умереть или навредить себе** | | | | |

**Шкала ответов:** 0 = Совсем нет, 1 = Несколько дней, 2 = Более половины дней, 3 = Почти каждый день

## Интерпретация суммы

| Сумма | Уровень |
|---|---|
| 0–4 | Минимальная депрессия |
| 5–9 | Лёгкая депрессия |
| 10–14 | Умеренная депрессия |
| 15–19 | Умеренно-тяжёлая депрессия |
| 20–27 | Тяжёлая депрессия |

## 🔴 Пункт 9 обрабатывается отдельно от суммы

**Любой ответ выше 0 на вопрос 9 — самостоятельный повод для немедленного обращения к врачу, независимо от общей суммы.** Он не «усредняется» с остальными пунктами и не компенсируется низким итогом. Это единственный пункт шкалы, который читается сам по себе.

## Оговорки

- Пункты 3, 4, 5, 7 и 8 — соматические и легко даются высокими при гипотиреозе, дефиците железа/B12, апноэ сна, побочных эффектах препаратов. У пациентов после бариатрических операций это особенно вероятно. Высокий балл по соматическим пунктам при низком по 1, 2 и 6 — скорее повод искать дефицит, чем депрессию.
- Пункт 5 у пациентов на GLP-1-агонистах отражает действие препарата, а не настроение.
- См. общие оговорки в [README.md](README.md).
