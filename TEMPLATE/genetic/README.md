# genetic/ — генетические данные

Сюда кладутся расшифровки геномов. **Содержимое этой папки не коммитится** — в `.gitignore` стоит `**/genetic/*` с исключением только для этого README:

```gitignore
**/genetic/*
!**/genetic/README.md
```

Проверить, что защита работает, **до** первого коммита рядом с данными:

```bash
git check-ignore -v пациент/genetic/genome.txt   # должен вывести правило из .gitignore
git status --porcelain пациент/genetic/          # должно быть пусто
```

Если `git status` показывает файл — он **не** игнорируется, коммитить нельзя.

---

## 🔴 Почему это не обычные персональные данные

Три свойства, которых нет у остальных медицинских записей:

1. **Геном неизменяем.** Утёкший пароль меняют, утёкший геном — нет. Это пожизненная утечка.
2. **Он не только ваш.** Каждый ребёнок разделяет с вами ~50% вариантов, каждый родитель и полный сибс — тоже, племянники ~25%. **Публикуя свой геном, вы публикуете часть генома родственников, которые об этом не просили.** Если в семье есть наследственное состояние, публикация одного профиля делает выводы о других членах семьи возможными.
3. **Деидентификация не работает.** Нескольких десятков SNP достаточно для однозначной идентификации, а по геному восстанавливают фамилию через открытые генеалогические базы. Убрать имя из файла — не значит анонимизировать его.

Отсюда практическое правило: **сырые данные не покидают локальную машину; интерпретация публикуется только осознанно и с пониманием, что она касается и родственников.**

## Что куда кладётся

| Что | Куда | В git? |
|---|---|:--:|
| Raw genotype (23andMe, AncestryDNA — `.txt`, ~15–25 МБ) | `пациент/genetic/` | ❌ |
| VCF (WGS/WES, ~1–5 ГБ; gVCF больше) | `пациент/genetic/` | ❌ |
| FASTQ (сырые риды, **100+ ГБ** на WGS) | внешний диск, в репозиторий не кладётся вообще | ❌ |
| BAM / CRAM + индексы `.bai`/`.crai` (десятки ГБ) | внешний диск или `пациент/genetic/` | ❌ |
| Отчёты лаборатории (PDF) | `пациент/genetic/` | ❌ |
| QC-отчёты (FastQC `.html`, MultiQC) | `пациент/genetic/analysis/qc/` | ❌ |
| Промежуточные файлы анализа (аннотированные, отфильтрованные VCF) | `пациент/genetic/analysis/` | ❌ |
| **Интерпретация** — `GENETICS.md` | `пациент/genetic/GENETICS.md` | ⚠️ решение владельца |
| Референсы: `hg38.fa` (~3 ГБ), gencode GFF3, BED-панели | `references/` в корне | ❌ велики и не ваши |
| Сторонние инструменты (SnpEff, VEP) | `tools/` | ❌ |

⚠️ **`GENETICS.md` — единственный файл, по которому требуется решение.** Сырых данных в нём нет, но есть **выводы о конкретных вариантах конкретного человека**, то есть это по-прежнему генетические данные. В приватном репозитории вопроса нет. В публичном — помните пункт 2 выше.

### Почему референсы тоже не в git

`hg38.fa` — около 3 ГБ, gencode-аннотации — сотни МБ. Git хранит все версии, и один такой коммит раздувает репозиторий необратимо (`git rm` историю не чистит). Референсы **скачиваются заново** по необходимости:

```gitignore
references/
tools/snpeff/
```

Ссылки на источники (UCSC, Ensembl, GENCODE) с версиями держите в `references/README.md` — этого достаточно для воспроизведения окружения.

## Поддерживаемые форматы

- **23andMe / AncestryDNA** — txt с raw data. Чипы на ~600–700 тыс. SNP: дают распространённые варианты, **редкие мутации не дают**
- **WGS** — VCF/gVCF. Полный геном, включая редкие варианты
- **WES** — VCF. Только экзоны (~2% генома), зато глубже покрытие
- **Панели** (фармакогенетика, наследственные заболевания) — обычно PDF, иногда с VCF

⚠️ **Чип и секвенирование не взаимозаменяемы.** Отсутствие варианта в чиповых данных означает «не проверялось», а не «нет варианта»: чип читает только заранее заложенные позиции. Выводы формулировать соответственно.

## Как использовать с AI-ассистентом

1. Положите файл(ы) в `пациент/genetic/`
2. Убедитесь, что `git status` их не видит
3. Ассистент читает их локально и пишет интерпретацию в `GENETICS.md`
4. Инструменты — в [`tools/`](../../tools/)

**Осторожности при интерпретации** (полный список — в [AGENTS.md](../../AGENTS.md) §Генетика):

- **Стренд.** C/T и A/G полиморфизмы могут быть записаны по минус-цепи — смысл генотипа переворачивается. Проверять в dbSNP/SNPedia **до** интерпретации.
- **Сцепление (LD).** Соседние маркеры часто наследуются вместе и независимыми сигналами не являются. Складывать их эффекты — значит считать одно и то же дважды.
- **Не перемножать эффекты.** «Три варианта по +20% = +73% риска» — это арифметика, а не биология. Использовать качественные формулировки.
- **Уровень доказательности** у каждого вывода: High / Medium / Low / Clinical. Большинство ассоциаций из популярных статей — Low.
- **Пенетрантность.** Наличие варианта риска не равно наличию состояния; для распространённых вариантов вклад в дисперсию признака — единицы процентов.

⚠️ **Ничто из этого не является медицинским заключением.** Клинически значимые находки (BRCA, HFE, фармакогенетика с реальными последствиями для дозирования) подтверждаются в сертифицированной лаборатории и обсуждаются с врачом-генетиком: потребительские чипы дают ложноположительные результаты по редким вариантам.
