## Дневник симптомов

Заполнять ежедневно. Нужен для (1) мониторинга терапии и (2) проверки сезонных гипотез — для второго требуется ряд **≥12 месяцев**.

> ⚠️ **Не заводить пустые заготовки на будущие месяцы.** Таблица создаётся тогда, когда появляется первая запись. Пустая таблица за прошедший месяц — мусор, создающий видимость наблюдения: в реальном досье такую пришлось удалить через 5 месяцев, за которые не появилось ни одной записи.

| Дата | Симптом 1 | Симптом 2 | Симптом 3 | Сон (ч) | Качество сна | Настроение | Кофе | Алкоголь | Препараты | Примечания |
|---|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|---|---|
| | | | | | | | | | | |

**Шкала**: 1–3 — слабо / почти нет · 4–6 — умеренно · 7–10 — сильно выражено.
**Настроение**: −5 (депрессия) … +5 (приподнятое).

**Колонки симптомов заменить на релевантные конкретному пациенту** — брать из [PROBLEMS.md](PROBLEMS.md), а не универсальный набор.

⚠️ **Что обязательно фиксировать помимо симптомов**, иначе ряд не читается:

- **Препараты** — приём по требованию (иначе эффект не отделить от фона)
- **Тренировочные дни** — влияют и на сон, и на АД
- **Кофеин и алкоголь** — оба конфаундят тревогу и сон
- **Внешние триггеры** — при подозрении на СДВГ-гиперфокус vs гипоманию решает именно **спонтанность** подъёма, а не его наличие

## ⚠️ Общие оговорки к самоотчётным шкалам

- **Это скрининг, а не диагноз.** Балл выше порога означает «нужна клиническая оценка».
- **При алекситимии самооценка эмоций систематически занижена** — низкий балл не равен отсутствию симптома. Проверить в [PROBLEMS.md](PROBLEMS.md), есть ли такая особенность у пациента.
- **Соматические пункты** (сон, утомляемость, аппетит, концентрация) легко даются высокими при гипотиреозе, дефиците железа/B12, апноэ сна и на фоне препаратов. Высокий балл по ним при низком по «настроенческим» пунктам — повод искать дефицит, а не депрессию.
- **Сравнивать только с собой** и только при одинаковых условиях заполнения.
