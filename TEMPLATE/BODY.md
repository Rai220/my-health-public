## Окружность талии

Пороги риска (WHO/IDF, европеоиды): **мужчины <94 см — норма**, 94–102 — повышенный риск, >102 — высокий; **женщины <80 — норма**, 80–88 — повышенный, >88 — высокий. Отношение талия/рост (WHtR): **<0.5 — норма** для всех.

| Дата | Талия (см) | WHtR | Вес (кг) | Методика / источник | Комментарий |
|---|---:|---:|---:|---|---|
| | | | | | |

🔴 **Протокол — без него точка бесполезна для сравнений.** Утром, натощак, после спокойного выдоха, лента горизонтально, **без втягивания живота**. Мерить сразу **в двух точках** и записывать обе:

1. **По протоколу WHO** — середина между нижним ребром и гребнем подвздошной кости (или на уровне пупка). Сопоставимо с порогами и с чужими данными.
2. **Самое узкое место** — у мужчин обычно выше и даёт **на 2–5 см меньше** протокольного. Годится для сравнения с собой, но не с порогом 94.

**Точку замера писать в колонку методики каждый раз.** Смена точки между замерами создаёт разницу больше реальной динамики.

## Обхваты конечностей (бицепс, бедро)

Не диагностические показатели — норм и порогов нет. Ценны как **трендовая метрика тощей массы конечности** в паре с талией: рост обхвата при стабильной талии = мышцы, рост обоих = общая прибавка массы. Сами по себе мышцы от жира не отличают.

| Дата | Бицепс расслабл. (см) | Бицепс напряж. (см) | Рука | Вес (кг) | Методика / источник | Комментарий |
|---|---:|---:|---|---:|---|---|
| | | | | | | |

🔴 **Протокол.** Точка — **середина плеча от костных ориентиров** (середина между акромионом и локтевым отростком), а не «на глаз». Записывать **два значения: расслабленная опущенная рука и напряжённая** — разница между ними 2–3 см, то есть больше любого реального прироста за квартал. **Указывать, какая рука** — доминирующая обычно на 0.5–1 см больше.

## Инструментальный состав тела (InBody / аналоги)

Профессиональная мультичастотная сегментная BIA (электроды на руки и ноги). Заметно точнее бытовых весов, но **это всё равно BIA, а не DEXA**: абсолютный % жира расходится с DEXA на единицы процентных пунктов. **Ценность — в повторяемости на одном приборе**, поэтому повторять на том же аппарате.

| Дата | Вес (кг) | Жир (кг) | Жир (%) | SMM (кг) | FFM (кг) | Талия (см) | Висц. жир | Методика / источник | Комментарий |
|---|---:|---:|---:|---:|---:|---:|---:|---|---|
| | | | | | | | | | |

**Что записывать обязательно**: вес, жировая масса, % жира, **SMM (скелетная мускулатура)**, FFM, талия, висцеральный жир, сегментная тощая масса по 5 сегментам (в комментарий).

**Что игнорировать полностью**: «оценка N/100», «рекомендуемый приём калорий», **BMR** — последний не измеряется, а считается из FFM по формуле (`21.6 × FFM + 370` у InBody), то есть информации сверх FFM не несёт, и пометка «ниже нормы» на нём смысла не имеет.

🔴 **Протокол повтора** (иначе сравнение развалится): утром, натощак, до воды и тренировки, не после алкоголя, **тот же прибор**, **тот же введённый рост** — если в первый раз рост введён с ошибкой, вводить так же, иначе ИМТ и оценки не сравнятся. Импеданс измеряет **воду**: обезвоживание завышает % жира, углеводная загрузка занижает.

⚠️ **Минералы «в норме» ≠ нормальная плотность костей.** BIA даёт общую минеральную массу тела и **МПК не измеряет** — денситометрию (DEXA) не заменяет. Особенно важно после бариатрических операций и при дефиците витамина D.

## Биоимпеданс (домашние весы)

Foot-to-foot одночастотная BIA. Абсолютные цифры недостоверны (ток идёт по ногам, туловище достраивается формулой), но **воспроизводимость приличная** → трендовая метрика, не измерение.

| Дата | Вес (кг) | Жир (%) | Тощая масса (кг) | Методика / источник | Комментарий |
|---|---:|---:|---:|---|---|
| | | | | | |

**Что записывать**: вес, % жира, тощая/мышечная масса. **Что игнорировать полностью**: «висцеральный жир», «метаболический возраст», «костная масса», «% белка» — производные той же одной цифры импеданса, отдельного смысла не несут.

**Протокол**: утром, после туалета, до еды и воды, до тренировки, босиком на слегка влажные стопы, не после алкоголя. Читать только среднее за 2–4 недели — отдельные замеры это шум.

> **Неочевидное преимущество весов**: техника замера почти не зависит от человека. Там, где самозамер лентой даёт разброс больше искомого эффекта, весы дают воспроизводимость. При соблюдении протокола BIA — **более надёжный трендовый канал, чем самозамер обхватов**, при том что абсолютные цифры недостоверны.

⚠️ **Противопоказание**: имплантированный кардиостимулятор / ИКД. Зубные имплантаты противопоказанием не являются.

> **Оговорка про силовые тренировки**: они добавляют мышечный гликоген и воду, BIA засчитывает это в тощую массу → направление тренда верное, величина завышена. Жир считается как «вес − тощая масса», поэтому ошибка переносится и туда.
